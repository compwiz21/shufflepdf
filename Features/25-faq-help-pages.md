# 25 — FAQ / Help

## Route
- `/faq`

## Content
Accordion of categorized questions:
- **Privacy & security**: Where do my files go? Is this really free? What about cookies?
- **What you can do**: list of every feature with screenshot or icon.
- **Troubleshooting**: file won't load, signature appears blurry, mobile experience.
- **Browser support**: Chrome 100+, Firefox 100+, Safari 15+, Edge 100+.
- **Roadmap**: planned features (OCR, PDF compression, form-fillable export).

## Files
- `src/app/faq/page.tsx`
- `src/components/landing/FAQ.tsx` (re-used)

## Acceptance
- All FAQ answered without external links (self-contained).
- JSON-LD `FAQPage` schema for SEO.
